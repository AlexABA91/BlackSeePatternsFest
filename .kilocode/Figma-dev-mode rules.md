# Figma-dev-mode rules.md

- The Figma Dev mode MCP Server providers an assets endpoint which can server image and SVG assets
- IMPORTANT: if Figma DEV Mode MCP Server returns a localhost source for an image or SVG, use that image or SVG source directly
- IMPORTANT: DO NOT import/add new icon packages, all the assets should be in the Figma payload
- IMPORTANT: do NOT use or create placeholder if a localhost source in provided
